## 📋 Description

Outil professionnel de suivi client conçu pour **Coach Rosy**, distributrice superviseure Herbalife en Guadeloupe.  
Ce système centralise la gestion des clients, des recommandations (parrainages), des rendez-vous et des communications automatisées.

---

## ✨ Fonctionnalités

| Module | Description |
|---|---|
| 📊 **Dashboard** | KPIs en temps réel, top clients, statistiques par commune |
| 👥 **Base Clients** | 29 clients avec coordonnées, suivi et historique |
| 🤝 **Recommandations** | 175+ filleuls potentiels, gestion du parrainage |
| 📅 **Calendrier RDV** | Planification interactive, rappels automatiques |
| ✉️ **Messages Auto** | 6 templates personnalisables (WhatsApp / SMS) |
| 🎁 **Suivi Cadeaux** | Soins visage, 2e et 3e cadeaux, statut en temps réel |

## 🚀 Démarrage rapide

### Option 1 — Application web (recommandée)
```bash
# Cloner le dépôt
git clone https://github.com/rosycoachoptimalnutritionbiene-wq/système-d-automatisation-Herbalife.git
cd système-d-automatisation-Herbalife

# Ouvrir directement dans le navigateur
open index.html
```

### Option 2 — Serveur local (Node.js)
```bash
npm install
npm start
# → http://localhost:3000
```
